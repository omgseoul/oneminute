Beds24 연결

기존 연결을 사용하면 Invite code를 다시 발급할 필요가 없습니다.

Marketplace → API에서 만든 Invite code를 입력하세요. 연결 후 코드는 지워지고 서버에 연결 정보가 안전하게 보관됩니다.

숙소 연결 설정

기존 Make 자동답변이 켜져 있어도 OMS의 AI 초안은 승인 전 발송되지 않습니다. 같은 문의에 두 번 답하지 않도록 기존 답변을 확인하세요.

웹훅 등록 주소

Beds24 → Properties → Access → Booking webhooks에서 Version 2로 등록하세요. 기존 Make 주소는 유지하고 이 주소를 추가하세요.

숙소를 선택하고 저장하면 주소가 표시됩니다.

최근 30일의 수신·처리 이력입니다. 기록 기능 적용 이후부터 표시됩니다.

메시지 번역

매월 제공량 안에서는 OMS 공용 번역을 사용합니다. 기본 제공량 이상으로 사용하려면 본인의 Google Cloud Translation API 키를 등록해주세요. 초과분은 개인 키로 처리되며 해당 Google 계정에 요금이 청구됩니다. AI 크레딧은 차감하지 않습니다.

개인 Google 번역 API 연결

공용 연결이 준비되지 않은 경우에도 등록한 개인 키를 사용합니다. 수신·발신의 입력 문자 수를 합산하며, 저장된 번역을 다시 볼 때는 차감하지 않습니다. 제공량은 매월 1일 한국시간에 갱신됩니다.
