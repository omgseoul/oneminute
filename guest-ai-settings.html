자동답변 불가 건 전달

비상, 재난 상황 전달

위치와 체크인 시간을 한 번에 물어도 관련 DATA를 함께 찾아 답합니다. 직원 전달은 위 설정에 따릅니다. 두 판단 스크립트는 기본 프롬프트와 합쳐 한 번에 적용됩니다.

AI 크레딧 사용량

1크레딧 = API 비용 US$0.001. 사용량·월 한도는 한국 시간 기준입니다. 처리 중에는 예상 최대 비용을 잠시 확보하고 응답 후 정산합니다.

최근 사용 내역

자동답변 DATA

한 행에 한 주제씩 입력하세요. 엑셀의 두 열을 복사해 붙여넣을 수 있습니다. 빈 답변은 AI가 참고하지 않습니다.

제목·답변 내용 두 열의 .xlsx 파일 · 최대 200행, 5MB. 업로드 후 표에 적용하고 설정 저장을 눌러주세요.

프롬프트 입력

말투와 응대 방식을 자유롭게 편집하세요. DATA에 없는 사실을 만들지 않기, 숙소별 정보 분리는 항상 적용됩니다. 전달 여부는 별도로 입력한 두 판단 스크립트와 알림 설정을 우선 적용합니다.

자동답변 불가 건 구분

AI가 어떤 문의를 직원이나 관리자에게 전달할지 판단하는 기준입니다. 게스트에게 그대로 보내는 답변 문구가 아닙니다.

안내 DATA에 정보가 없거나 직원의 확인·처리가 필요한 상황을 구체적으로 적어주세요.

작성 예시

DATA에 필요한 정보가 없거나 예약 확인 등 직원의 처리가 필요한 문의를 전달합니다. 비상·재난 상황은 제외합니다.

전달 기능을 켜고 알림 받을 대상을 선택해야 알림이 발송됩니다. 두 조건에 모두 해당하면 비상·재난 전달이 우선합니다.

비상·재난 상황 구분

AI가 즉시 확인이나 조치가 필요한 상황을 구분하는 기준입니다. 숙소에서 비상으로 처리할 상황을 자유롭게 추가하거나 수정하세요.

작성 예시

문이 열리지 않거나 객실에 갇힘, 물이 나오지 않음, 화재·연기·가스 누출, 신변 위협이나 침입자가 있는 상황을 전달합니다.

전달 기능을 켜고 알림 받을 대상을 선택해야 알림이 발송됩니다. 알림 강도는 직원·관리자별로 선택한 설정을 따릅니다.
