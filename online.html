매월 제공량 안에서는 OMS 공용 번역을 사용합니다. 초과분은 등록한 개인 Google Cloud Translation API 키로 처리되며 해당 Google 계정에 요금이 청구됩니다. AI 크레딧은 차감하지 않습니다.

기본 번역 언어는 게스트 메시지의 번역 버튼에 적용됩니다. 이미 같은 언어이면 원문을 유지합니다. 답변 작성의 상대 언어 선택과는 별개입니다. 자동번역은 펼친 메시지와 대화 화면에 적용되며, 제외 언어도 수동 번역할 수 있습니다. 언어가 확인되지 않은 메시지는 먼저 언어를 확인하며, 이때 처리한 문자도 제공량에 합산됩니다.

수신·발신 입력 문자 수를 합산하며, 저장된 번역을 다시 볼 때는 차감하지 않습니다. 제공량은 매월 1일 한국시간에 갱신됩니다.
