객실 · 도어락 매칭

OMS 객실, Beds24 객실·유닛, 해당 도어락을 연결하세요. 공용 출입문은 모든 연결 객실에 함께 등록됩니다.

비밀번호 생성 방식

전화번호 → 모바일 번호 순으로 확인합니다. 번호가 없거나 짧거나 다른 예약과 중복되면 랜덤으로 생성합니다.

기존 Lock info가 있으면 발급을 중단하고 봇으로 알립니다. 기존 값을 삭제한 뒤 처리 내역에서 재시도하세요.

예약별 처리 내역

자동 발급 시작

연결한 객실의 비밀번호를 생성하고 Beds24 LOCK_PIN에 기록합니다. 예약 취소·숙박 종료 시 OMS가 발급한 비밀번호를 정리합니다.
